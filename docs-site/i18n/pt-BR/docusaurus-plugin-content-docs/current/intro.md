# Introdução

Bem-vindo ao **SlicePizza**: um projeto prático de aprendizado de DevOps construído em torno de um
sistema de pedidos online para uma pizzaria fictícia, a **Pizzaria do Zé**.

O sistema começa pequeno e cresce em fases. A cada fase, o "dono da pizzaria"
pede algo novo, e esse pedido obriga você a aprender uma nova tecnologia:
Docker, DNS, nuvem, filas, CI/CD, observabilidade, Terraform e Kubernetes.

> A ideia é **sentir o problema antes de usar a ferramenta**.

## O que você vai encontrar aqui

- **[Tour do produto](/docs/tour)**: capturas de tela do sistema rodando.
- **Guias das fases**: o que o Zé pediu e como o sistema evolui para atender.
- **Notas técnicas**: como a API, o banco de dados e a stack Docker se encaixam.
- **[ADRs](/adr)**: registros de decisões de arquitetura que explicam por que cada escolha foi feita (em inglês).

Comece pela [visão geral da Fase 1](/docs/phase-1/overview).
